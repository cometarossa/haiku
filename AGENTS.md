# AI-assisted Haiku research fork: cometarossa/haiku

This file applies **only to the `ai-experimental` branch of the
`cometarossa/haiku` fork**. The `master` branch tracks upstream.

## Scope and provenance

- AI-assisted source code, scripts, experiments, and documentation are
  permitted **inside this independent research fork**, and must be
  plainly labeled as AI-assisted.
- The original Haiku project at https://github.com/haiku/haiku explicitly
  does **not** accept AI-generated or AI-modified code, documentation,
  or other contributions. Respect its policy without exceptions.
- **Never open an upstream pull request, Gerrit change, or submit any
  AI-assisted changes to Haiku upstream.** No workaround or attribution
  laundering. Human-verified issue reports must obey upstream rules.
- Preserve upstream copyrights and license notices. Keep experiments
  isolated where possible, review changes and run meaningful tests.
- Do not overwrite the persistent Haiku VM disk or production storage.
  Experimental images must be separate, disposable copies.
- Virtualization is for correctness, reproducibility and debugging;
  never present VM results as native hardware performance benchmarks.

For our experimental development workflow, see
`experiments/ai-lab/README.md`.
